# Hi there, I'm Abdulrahman Mohamed 👋

Welcome to the repository of my personal portfolio website! I built this project to showcase my professional background and bridge my core expertise as a **Senior General Accountant** with modern **Financial Data Analytics** and business intelligence tools.

You can check out the live version of the website here: **[My Portfolio Live Link](https://my-portfolio-cyan-six-hsft2er28e.vercel.app)** 

---

## 💡 About This Project

As someone with over 7 years of experience in financial accounting and general ledger operations, I wanted my portfolio to reflect both my traditional financial background and my technical skills in data science. I designed and developed this website to be fast, responsive, and interactive, featuring smooth dark/light mode toggles, custom particle backgrounds, and 3D card tilt effects.

---

## 🛠️ Tech Stack I Used

* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS
* **Icons:** Lucide React
* **Hosting & Deployment:** Vercel
* **Version Control:** Git & GitHub

---

## 🌟 Key Pages & Sections

* **Homepage (`/`):** Features my hero introduction with my professional photo, quick action buttons (Resume download, Contact, Socials), featured data analysis projects, and direct contact options.
* **Skills Page (`/skills`):** A dedicated, categorized breakdown of my technical stack—ranging from Python, SQL Server, Power BI, and Advanced Excel to Financial Statements Preparation and General Ledger management, complete with proficiency percentages and star ratings.
* **About Page (`/about`):** A comprehensive timeline of my professional experience (including my role at Emessa Denim and remote freelance data analyst work), education from Al-Azhar University, and professional certifications (DEPI, IBM, CMA Candidate, Oracle AI, CFI).
